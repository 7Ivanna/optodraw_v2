Quick start
  1. Add parts — drag from the left palette onto the canvas.
  2. Connect — the Route/Links tool draws beams (free-space) or waveguides (chip).
  3. Choose a view — 1D for compact diagrams, 2D for layouts, or 3D for spatial scenes.
  4. Export — PNG, GLB, TikZ, or a publication figure.
