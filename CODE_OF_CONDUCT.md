# Code of conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent to people. Assume good faith, critique the work rather than
the person, and accept that a maintainer with a day job may be slow.

Report unacceptable behaviour with **Report a vulnerability** on the repository's
Security tab. Only the maintainer reads these reports.
