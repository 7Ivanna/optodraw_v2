# Tutorial notebooks

These notebooks are generated and executed by
`python generate_tutorial_notebooks.py --execute`.
The cells measure drawn extent, place with `chain_ports`, and route with
`path_type="smooth"`. Use `scene.preview()`. Do not paste `render_svg()`
into a cell.

Simple demos:

- `fold_and_focus.ipynb`
- `polarization_bench.ipynb`
- `gc_ring_photodetector.ipynb`
- `four_f_relay.ipynb`

Paper reconstructions (cite the source paper):

- `bogaerts_add_drop.ipynb`
- `reed_mzm_probe.ipynb`
- `smit_awg_demux.ipynb`
- `tait_weight_bank.ipynb`
- `conchello_confocal.ipynb`

Registry smoke plots stay in `quickplot_*.ipynb`.
Do not treat research notebooks in this folder as package tutorials.
